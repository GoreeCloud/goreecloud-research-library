# GoreeCloud Research Library — Branding

## Product name

Use **GoreeCloud Research Library** in user-facing product text. The repository identifier remains `goreecloud-research-library`.

## Visual system

The current UI targets the current Stable Glaze UI contract, version 1.1.0, while formal rendered/contract acceptance remains pending.

Current design principles used by the MVP:

- readable research content uses solid, high-legibility surfaces;
- transient navigation/search/control chrome may use glazed material;
- Deep Teal is the primary interaction accent in the Stable 1.1 atmosphere;
- Soft Amber is subordinate and is not used as a substitute for semantic warning state;
- semantic success/error/focus meaning takes precedence over decoration;
- reduced-motion preferences are honored;
- responsive layouts preserve usable touch targets and readable content.

## Logo and artwork rule

Do not invent, redraw, or embed an unofficial GoreeCloud logo merely to fill UI space. Use the currently approved GoreeCloud brand asset from its canonical branding source when that asset is integrated. Until then, the Development UI uses the product name as a text wordmark rather than a fabricated logo.

Favicon, application icon, social-preview artwork, and other packaged brand assets must use current approved artwork before a public release surface is considered complete.

## Glaze UI lifecycle rule

A Candidate or draft Glaze UI version must not silently become this application's Stable requirement. Adoption requires the applicable governed promotion and downstream validation. The Platform Contract is the machine-readable statement of current conformance status.
